# Contributing

Norevify is a live, monetized product (see [LICENSE](LICENSE) — proprietary,
all rights reserved). This repository is public for **portfolio review**,
not as an open-source project.

**This project is not accepting pull requests or code contributions.** Forks
for personal reference are fine to read, but reused, modified, or
redistributed code is not licensed for that use — see the LICENSE.

Bug reports and vulnerability reports are still welcome:

- **Security issues** → see [SECURITY.md](SECURITY.md), do not open a public
  issue
- **Bugs / UX findings** → [GitHub Issues](../../issues) are open for these;
  a repro-steps + expected/actual + severity format (see the existing closed
  issues for examples) is appreciated but not required

If you're here evaluating the codebase or test suite as part of a hiring
process or similar, feel free to reach out — contact details are in the
[README](README.md#author).
